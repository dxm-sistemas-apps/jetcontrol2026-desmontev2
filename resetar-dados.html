Resetar Todos os Dados

Isso apaga permanentemente, sem volta:

  • Todos os dados salvos neste navegador (ciclos, escalas, cotas extras, valores etc.)
  • Todos os dados salvos na nuvem (Firestore), usados para sincronizar entre aparelhos

Reset a partir da origem: você só precisa rodar isto UMA VEZ, em UM aparelho. Todos os outros navegadores/aparelhos que já usaram o sistema vão se limpar sozinhos automaticamente na próxima vez que abrirem qualquer página (não é preciso clicar em "resetar" em cada um).

Isso só funciona em aparelhos que abrirem o sistema DEPOIS do reset (com internet no momento em que abrirem). Um aparelho que nunca mais for aberto, obviamente, continua com os dados antigos salvos nele até que seja aberto de novo.
